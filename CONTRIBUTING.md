# Contributing to Aurora

Thank you for considering contributing to Aurora.

## Ways to contribute

- Report bugs and request features through issues.
- Improve documentation and architecture notes.
- Submit pull requests for implementation work.
- Help review changes and share feedback.

## Before you start

- Read the architecture documentation in docs/.
- Keep changes focused and scoped to one logical improvement.
- Follow the repository's naming, formatting, and testing conventions.

## Pull request expectations

- Open a pull request with a clear summary and motivation.
- Keep the change small and reviewable.
- Include tests where applicable.
- Ensure documentation remains up to date.

## Code of conduct

Please review the code of conduct before participating in the project.
