# User Guide

Aurora is a modular desktop shell experience for Hyprland users.

## Getting started

- Install the required dependencies for your Hyprland environment.
- Review the default configuration before changing anything.
- Launch Aurora from your desktop session.

## Main features

- Use the dashboard for an overview of the desktop experience.
- Access notifications from the notification area.
- Launch apps from the launcher surface.
- Adjust settings through the control center.

## Troubleshooting

- Check the configuration files first when something behaves unexpectedly.
- Confirm that required services are running.
- Review logs and error output before editing system files.
