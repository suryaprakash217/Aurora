# Developer Guide

Use this guide when contributing to Aurora.

## Setup

- Work in a Python 3.11+ environment.
- Keep dependencies isolated in a virtual environment.
- Review the repository layout before editing modules.

## Workflow

1. Read the architecture overview.
2. Add or update tests for any behavior change.
3. Keep the change focused on one concern.
4. Prefer small, reviewable edits.
5. Update the docs if user-facing behavior changes.

## Contribution expectations

- Keep features modular and easy to reason about.
- Separate UI code from core logic where possible.
- Use configuration-driven behavior rather than hard-coded values.
- Document new features clearly.
